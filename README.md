# 🎵 YouTube Playlist to MP3 Converter (Qualidade Máxima 320kbps)

Aplicativo moderno em Python com interface gráfica (CustomTkinter) para baixar playlists completas e vídeos do YouTube / YouTube Music diretamente em formato MP3 de alta fidelidade.

## ✨ Recursos

- **Qualidade Máxima:** Conversão para MP3 em 320 kbps (CBR) ou VBR 0 via FFmpeg.
- **Capa do Álbum Embutida:** Baixa a thumbnail do vídeo em alta resolução e embute diretamente no arquivo `.mp3` (ID3 APIC).
- **Metadados Completos:** Adiciona Artista, Título e Álbum automaticamente nas tags ID3.
- **Organização Inteligente:** Opção de criar uma pasta dedicada com o nome da playlist e numerar as faixas sequencialmente (`01 - `, `02 - `).
- **Progresso em Tempo Real:** Mostra velocidade (MB/s), tempo restante (ETA) e lista interativa de faixas com status individual.
- **Suporte a YouTube Music:** Aceita tanto links normais do YouTube quanto playlists do YouTube Music.
- **Cancelamento Seguro:** Permite interromper o download a qualquer momento sem travar o aplicativo.

## 🚀 Como Iniciar

Dê dois cliques no arquivo **`Baixar Playlists MP3.bat`** na sua Área de Trabalho ou execute:

```bash
python app.py
```
